## 🛠️ Tools & Utilities (`/usr/bin/tools`)
*Item count: 06*

1. **[Anything to PDF](https://nekonyan.fun/anything-to-pdf)** ([GitHub](https://github.com/quincynyan/anything-to-pdf))
   - *Type:* `client-side virtual printer`
   - A browser-based virtual printer that converts printable files into PDFs entirely on your device, supporting office documents, spreadsheets, presentations, images, scans, ebooks, email, video contact sheets, and source code.

2. **[PDF Resizer](https://nekonyan.fun/PDF-Resizer)** ([GitHub](https://github.com/quincynyan/PDF-Resizer))
   - *Type:* `client document scaler`
   - A client-side PDF tool for fitting mixed documents to A4 or making page widths consistent, with reordering and batch, combined, or ZIP export.

3. **[Sorter](https://nekonyan.fun/sorter)** ([GitHub](https://github.com/quincynyan/sorter))
   - *Type:* `pairwise ranking engine`
   - A small pairwise sorting experiment: compare two things at a time and use the choices to work toward a ranking.

4. **[Text to Morse](https://nekonyan.fun/Text-to-Morse)** ([GitHub](https://github.com/quincynyan/Text-to-Morse))
   - *Type:* `dit-dah bidirectional encoder`
   - A browser utility for converting text to Morse code and decoding Morse back into text.

5. **[Unicode Fractions](https://nekonyan.fun/UnicodeFractions)** ([GitHub](https://github.com/quincynyan/UnicodeFractions))
   - *Type:* `powercord unicode plugin`
   - A Powercord plugin for producing fraction-like Unicode text from arbitrary numerators and denominators using superscript and subscript characters.

6. **[Change Taskbar Icon](https://nekonyan.fun/change_taskbar_icon)** ([GitHub](https://github.com/quincynyan/change_taskbar_icon))
   - *Type:* `powershell win32 script`
   - A Windows PowerShell experiment for assigning custom taskbar icons to Microsoft Store applications.
